
# Business Automation Bridge

Система автоматизации обработки клиентских заявок на базе Python.

## О проекте

Business Automation Bridge — приложение для автоматизации сбора, хранения и обработки заявок клиентов.

Система объединяет веб-форму, базу данных SQLite, Telegram-уведомления и Google Sheets.

## Основные возможности

- Приём заявок через веб-форму.
- Сохранение заявок в SQLite.
- Уведомления о новых заявках в Telegram.
- Двусторонняя синхронизация SQLite и Google Sheets.
- Автоматическая синхронизация каждые 30 секунд.
- Административная панель для управления заявками.
- Изменение статусов заявок.
- Обнаружение конфликтов при синхронизации.
- Ручное разрешение конфликтов через админку.
- Журнал событий синхронизации.
- Защита административных API с помощью HTTP Basic Authentication.

## Технологии

- Python
- FastAPI
- SQLite
- Google Sheets API
- Telegram Bot API

## Установка

### 1. Клонирование проекта

```bash
git clone <repository-url>
cd business-automation-bridge
```

### 2. Создание виртуального окружения

Windows:

```powershell
python -m venv .venv
.venv\Scripts\activate
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`.

Заполните необходимые настройки Telegram, Google Sheets и административного доступа.

### 5. Настройка Google Sheets

1. Создайте проект в Google Cloud.
2. Включите Google Sheets API.
3. Создайте Service Account.
4. Скачайте JSON-ключ.
5. Поместите его в `credentials/service_account.json`.
6. Предоставьте сервисному аккаунту доступ к нужной таблице.

### 6. Запуск

```bash
uvicorn app.main:app --reload
```

После запуска:

- Веб-форма: http://127.0.0.1:8000/
- Админ-панель: http://127.0.0.1:8000/admin
- Проверка состояния: http://127.0.0.1:8000/health

## Синхронизация данных

Приложение поддерживает двустороннюю синхронизацию между SQLite и Google Sheets.

При обнаружении одновременного изменения одного поля в обеих системах создаётся конфликт.

Администратор может выбрать, какое значение оставить:

- Значение из SQLite.
- Значение из Google Sheets.

После выбора система обновляет обе стороны и закрывает конфликт.

## Безопасность

- Административные API защищены авторизацией.
- Доступ к Google Sheets осуществляется через Service Account.
- Секретные данные хранятся в переменных окружения и отдельных файлах.
- Файл `.env` и ключи доступа не должны попадать в публичный репозиторий.
