# Business Automation Bridge

**Система автоматизации клиентских заявок с интеграцией Telegram и Google Sheets на базе FastAPI.**

Business Automation Bridge — демонстрационный проект автоматизации бизнес-процессов. Приложение объединяет сбор заявок, хранение данных, уведомления и синхронизацию между несколькими системами в едином интерфейсе.

## Возможности

### Обработка заявок
- Приём клиентских заявок через веб-форму.
- Сохранение данных в SQLite.
- Просмотр заявок в административной панели.
- Редактирование имени, телефона, услуги и комментария.
- Изменение статусов заявок.
- Поиск и фильтрация заявок.

### Интеграции
- Telegram-уведомления о новых заявках.
- Интеграция с Google Sheets API.
- Двусторонняя синхронизация SQLite и Google Sheets.
- Автоматическая синхронизация каждые 30 секунд.

### Контроль синхронизации
- Обнаружение конфликтов при изменении одних и тех же данных.
- Просмотр конфликтов в административной панели.
- Разрешение конфликтов с выбором источника данных.
- Журнал событий синхронизации.
- Регистрация ручного редактирования заявок.

## Интерфейс

Проект включает две веб-страницы:

- **Клиентская форма** — для отправки заявок.
- **Административная панель** — для управления заявками, просмотра статистики, контроля синхронизации и разрешения конфликтов.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/soulwound/business-automation-bridge.git
cd business-automation-bridge
```

### 2. Создание виртуального окружения

Windows:

```powershell
python -m venv .venv
.venv\Scripts\activate
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка окружения

Создайте файл `.env` на основе `.env.example`.

Заполните необходимые параметры:

| Переменная | Назначение |
|---|---|
| BOT_TOKEN | Токен Telegram-бота |
| ADMIN_ID | Telegram ID администратора |
| SPREADSHEET_ID | ID Google-таблицы |
| ADMIN_USERNAME | Логин администратора |
| ADMIN_PASSWORD | Пароль администратора |

### 5. Настройка Google Sheets

1. Создайте проект в Google Cloud.
2. Включите Google Sheets API.
3. Создайте Service Account.
4. Скачайте JSON-ключ сервисного аккаунта.
5. Поместите файл в `credentials/service_account.json`.
6. Предоставьте сервисному аккаунту доступ к Google-таблице.

### 6. Запуск

```bash
uvicorn app.main:app --reload
```

После запуска приложение будет доступно по адресам:

| Раздел | Адрес |
|---|---|
| Клиентская форма | http://127.0.0.1:8000/ |
| Административная панель | http://127.0.0.1:8000/admin |
| Проверка состояния | http://127.0.0.1:8000/health |

## Как работает синхронизация

Приложение поддерживает двусторонний обмен данными между SQLite и Google Sheets.

1. Изменения обнаруживаются при очередном цикле синхронизации.
2. Система сравнивает данные между источниками.
3. При обнаружении конфликтующих изменений создаётся запись о конфликте.
4. Администратор выбирает, какой источник считать актуальным.
5. Выбранное значение применяется к обеим системам.
6. Результат операции фиксируется в журнале.

Автоматическая синхронизация запускается каждые 30 секунд.

## Безопасность

- Административные API защищены HTTP Basic Authentication.
- Доступ к Google Sheets осуществляется через Service Account.
- Секретные параметры хранятся в `.env`.
- Файлы с ключами доступа и локальная база данных исключены из Git через `.gitignore`.

**Не публикуйте реальные токены, пароли и JSON-ключи в публичном репозитории.**
